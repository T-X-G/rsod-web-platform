## 三、钢材表面缺陷6类目标信息

| ID | 英文名称              | 中文名称  | 描述              |
| -- | ----------------- | ----- | --------------- |
| 0  | crazing           | 裂纹    | 钢材表面的裂纹类缺陷      |
| 1  | inclusion         | 夹杂物   | 钢材中的非金属夹杂物缺陷    |
| 2  | patches           | 斑点    | 钢材表面的斑点状缺陷      |
| 3  | pitted\_surface   | 麻面    | 钢材表面的麻点、凹坑类缺陷   |
| 4  | rolled\_in\_scale | 轧入氧化皮 | 钢材轧制过程中形成的氧化皮缺陷 |
| 5  | scratches         | 划痕    | 钢材表面的划痕类缺陷      |
